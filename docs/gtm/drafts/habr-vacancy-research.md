# Черновик для Хабра: «Проанализировали N вакансий {роль}: что реально спрашивают»

> Куда публиковать: Хабр, хаб «Карьера в IT-индустрии» (+ профильный хаб роли).
> Это НЕ готовый текст — это каркас + метод сбора данных. Статью публикуем, когда
> данные собраны (вечер работы). Формат «данные + выводы» на Хабре живёт годами,
> прямая реклама режется модерацией — поэтому продукт упоминается один раз, в конце.

## Шаг 1. Собрать данные (1 вечер)

В приложении уже есть генератор вероятных вопросов по вакансии (`apps/api-py`).
Скрипт-прогон:

1. Взять `N = 100+` свежих вакансий роли X с hh.ru (ручной экспорт или API hh —
   без ключа до 1000 запросов/день).
2. Прогнать каждую через генератор вопросов (локально, своим ключом).
3. Нормализовать вопросы → кластеризовать по темам (руками или эмбеддингами).
4. Получить таблицу: тема → % вакансий, где она всплывает → пример вопроса.

Роль для первого прогона: **QA manual** (самый большой трафик в наших SEO-страницах)
или **Frontend**.

## Шаг 2. Каркас статьи

1. **Хук:** «Мы прогнали N актуальных вакансий {роль} через ИИ и посчитали, какие темы
   всплывают чаще всего. Спойлер: то, что советуют гуглить, и то, что спрашивают —
   разные списки».
2. **Методология** (коротко, честно): как собирали, сколько вакансий, ограничения
   («это вероятностная оценка по текстам вакансий, а не статистика реальных интервью»).
   На Хабре за методологию спрашивают жёстко — ответить в комментариях.
3. **3–5 графиков/таблиц**: топ тем по частоте; сравнение «джун vs мидл»; темы,
   которые есть в каждой второй вакансии, но отсутствуют в популярных подборках вопросов.
4. **5 неожиданных вопросов** из выборки с комментарием, зачем их спрашивают.
5. **Выводы для кандидата:** на что тратить вечера подготовки, а что можно не зубрить.
6. **Ссылка (одна, в конце):** полный банк вопросов по этой роли с разбором —
   https://skill-cue.ru/voprosy/{rol}.html?utm_source=habr&utm_medium=article&utm_campaign=vacancy-research-{rol}
   + одна строка: «инструментом, которым считали, пользуемся сами, вот он». Без продаж.

## Шаг 3. Правила выживания на Хабре

- Тон: исследование, не маркетинг. Слово «уникальный» = минус в карму.
- Отвечать на комментарии развёрнуто первые 2 дня — от этого зависит попадание в ленту.
- Если пост уходит в минус — это тоже данные: значит, рынок считает иначе, разбираем почему.
- Второй пост через 2–3 недели по другой роли: серия работает лучше одиночек.

## Альтернатива, если лень собирать данные

Переписать в формат «Как я готовился к N собеседованиям и что заметил» — личный опыт
с цифрами (сколько прогонов, что спрашивали на реальных) тоже заходит. Но исследование
по данным сильнее для ссылочного профиля.
