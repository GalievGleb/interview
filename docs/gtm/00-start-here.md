# 00 — START HERE: запуск за 3 вечера, по шагам

Этот файл для состояния «сложно представить, как всё это реализовать». Не думай о всём
плане сразу — просто иди по шагам сверху вниз. Каждый шаг — конкретное действие на 10–40 минут.

Воронка, которую запускаем (решение от 2026-07-05, уточнено вечером):
**лендинг → «Скачать для Windows» → бесплатный старт без карты (1–2 разбора + 15 мин live,
лимит по объёму, не по дням) → оплата внутри приложения.**
Резервный вход для тех, кто не готов качать .exe: Telegram-бот «пришли вакансию — вернём разбор».

## Вечер 1 — точка входа работает (≈ 2 часа)

### Шаг 1. Инсталлер на GitHub Releases (30–60 мин)

Кнопки лендинга уже ведут на `github.com/GalievGleb/interview/releases/latest`.

⚠️ **Нюанс: если репозиторий приватный — посетители получат 404.** Код открывать не нужно:
создай отдельный **публичный** репозиторий только для бинарей, например `skillcue-releases`,
и публикуй инсталлеры туда. Тогда ссылку на лендинге поменяй на
`github.com/<твой-логин>/skillcue-releases/releases/latest`.

```powershell
# собрать инсталлер (из корня репозитория)
pnpm dist:desktop
# результат в apps/desktop/release/ — файл SkillCue-Setup-*.exe
```

Затем: GitHub → репозиторий для релизов → Releases → «Draft a new release» → tag `v0.1.0` →
перетащить .exe → Publish.
