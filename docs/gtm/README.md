## Стратегия в одном абзаце

Продаём **подготовку и уверенность на собеседовании**, а не «читерство»: лид-магнит —
бесплатный разбор вакансии (вероятные вопросы + риски), монетизация — Pro (системная
подготовка) и Live (overlay-подсказки). Рынок старта — RU IT-соискатели (QA, тестировщики,
джуны/мидлы — они чаще всех проходят собеседования и активнее всех сидят в Telegram).
Первые 30–50 клиентов — руками в Telegram-сообществах поиска работы, параллельно строим
SEO-актив (банки вопросов по ролям) и Shorts-демо overlay. Через 90 дней — решение об
EN-экспансии по цифрам.

## С чего начать

Открой [00-start-here.md](00-start-here.md) — там весь запуск разложен на 3 вечера
конкретных шагов (инсталлер → бот → домен → метрика → оплата → первые 10 пользователей).
Заполняй weekly-трекер из [03-funnel-metrics.md](03-funnel-metrics.md) каждое воскресенье —
без цифр весь план мёртв.
