# 04 — SEO и контент: бесплатный трафик как актив

SEO — единственный канал, который дешевеет со временем. Начинаем со 2-й недели, эффект
через 2–4 месяца (Яндекс быстрее Google для RU). Всё под RU-выдачу: **Яндекс — приоритет №1**, Google — №2.

## 1. Семантическое ядро: 4 кластера

### Кластер A — «вопросы на собеседовании <роль>» (главный, самый жирный)
Интент идеально наш: человек готовится к собесу прямо сейчас.

Шаблоны запросов: `вопросы на собеседовании QA`, `что спрашивают на собеседовании тестировщика`,
`вопросы на собеседовании джава разработчик с ответами`, `вопросы на техническом интервью frontend`.

**Механика — programmatic SEO:** у продукта уже есть генерация вероятных вопросов по вакансии.
Делаем из этого 30–100 статических страниц: «Вопросы на собеседовании: {Роль} {Грейд} в 2026»
(QA manual/auto, frontend, backend Java/Python/Go, аналитик данных, системный аналитик, DevOps,
продакт, проджект, 1С, техподдержка…). Каждая страница: 20–40 вопросов с короткими ответами
+ «слабые темы» + CTA «вставь СВОЮ вакансию — получи персональный список бесплатно».

- [x] **16 страниц ролей готовы:** `landing/voprosy/` — хаб + QA manual/auto, Frontend,
      Python, Java, DevOps, системный аналитик, продакт, проджект, 1С, Data Science +
      выход за IT (тест сработал): бухгалтер, маркетолог, HR, менеджер по продажам,
      оператор поддержки. Каждая: 14–18 вопросов «что хотят услышать», FAQPage-разметка,
      canonical+OG, CTA в бота.
- [x] **Кластер B и C:** гайды `kak-podgotovitsya-za-3-dnya.html`,
      `rasskazhite-o-sebe.html`; сравнения `skillcue-vs-chatgpt.html` и
      `skillcue-vs-mentor.html`; кластер E: `ii-intervyu.html`.
      Sitemap: 24 URL.
- [x] **Тех. SEO выровнено (2026-08-24):** все title ≤64 знака; canonical + OG-теги на всех
      страницах; Яндекс.Метрика 110472034 на всех страницах, включая главную и EN;
      UTM (`utm_source=site&utm_medium=article&utm_campaign=<page>`) на всех CTA в бота.
- [ ] После каждого деплоя лендинга: «Переобход страниц» в Вебмастере; через 3–4 недели
      смотреть показы в отчёте «Запросы»

### Кластер B — «как подготовиться к собеседованию»
`как подготовиться к собеседованию за 1 день`, `как подготовиться к техническому интервью`,
`как отвечать расскажите о себе`, `как справиться с волнением на собеседовании`.
Формат: 5–10 лонгридов-гайдов. Конкуренция выше, зато шарятся в TG.

### Кластер C — категорийные и брендовые
`ai помощник для собеседования`, `тренажёр собеседований онлайн`, `мок интервью онлайн бесплатно`,
`interview copilot на русском`, `аналог final round ai`. Частотность ниже, интент — горячий,
конверсия максимальная. 5–7 страниц, включая честные сравнения: «SkillCue vs ChatGPT для
подготовки», «SkillCue vs мок-интервью с ментором» (формат сравнения = конверсионный магнит).

### Кластер D — «разбор вакансии» / инструмент
`анализ вакансии`, `какие вопросы зададут по вакансии`. Низкочастотник, но это страница
нашего бесплатного веб-инструмента — она же лендинг лид-магнита. Инструмент в выдаче
(«вставь вакансию — получи вопросы») собирает ссылки сам.

### Кластер E — «ии + собеседование» (приоритет основателя, 2026-08-24)
`ии интервью`, `собеседование с ии`, `собеседование с нейросетью`, `ии проводит
собеседование`, `ии для подготовки к собеседованию`. Растущий горячий интент.
- [x] `ii-intervyu.html` — информационный гайд (что такое ИИ-интервью, кто проводит,
      какие вопросы задаёт бот, 7 правил ответа, FAQPage-разметка), перелинковка с хабом.
- [x] Главная переориентирована на коммерческий интент: title «…подготовку к собеседованию
      с ИИ…», описание и eyebrow с «ИИ».
- **Решение по «новым сайтам»: не создавать.** Новый домен = песочница Яндекса на месяцы,
  нулевой доверие, размазанные силы. Растём одним доменом; для быстрого охвата того же
  трафика — площадки, которые уже ранжируются в Яндексе: Дзен, Хабр, vc.ru, Pikabu,
  YouTube (см. [09-seo-execution.md](09-seo-execution.md)).

## 2. Технический SEO-чеклист лендинга

- [x] Каждой странице — уникальные `title` (все ≤ 64 знака, с ключом) и `description` (2026-08-24)
- [x] H1 = запрос кластера; структура H2/H3 по подвопросам («Люди также спрашивают»)
- [x] Schema.org: `FAQPage` для банков вопросов, `SoftwareApplication` для главной
- [x] `sitemap.xml` + `robots.txt`; canonical + OG на каждой странице (2026-08-24).
      Регистрация в Яндекс.Вебмастер и Google Search Console — см. [09-seo-execution.md](09-seo-execution.md)
- [ ] Скорость: лендинг статический — уже хорошо; картинки в WebP, lazy-load
- [x] ЧПУ-урлы: схема `/voprosy/{rol}.html` + гайды в корне — выдержана по всему сайту
- [x] Перелинковка: банки вопросов → хаб и соседние роли; сравнения связаны между собой
      и стоят карточками в хабе «Гайды»
- [ ] Турбо-проверка: после индексации смотреть в Вебмастере «Запросы» → дописывать страницы под то, что уже показывается на 5–20 позициях (самый дешёвый рост)

## 3. Контент-план на 8 недель (реалистичный для одного человека)

| Неделя | Публикации |
|---|---|
| 2 | Страница-инструмент «Разбор вакансии бесплатно» (кластер D) + 2 страницы вопросов (QA manual, QA auto) |
| 3 | 3 страницы вопросов (frontend, Java, Python) |
| 4 | Гайд «Как подготовиться к собеседованию за 3 дня» + 2 страницы вопросов |
| 5 | Сравнение «SkillCue vs ChatGPT» + 2 страницы вопросов |
| 6 | Гайд «Расскажите о себе: формула ответа» + 2 страницы вопросов |
| 7 | Сравнение «SkillCue vs мок-интервью с ментором» + 2 страницы вопросов |
| 8 | Ревизия: что индексируется, что на 5–20 позиции → усилить эти страницы |

Правило: **каждая статья заканчивается формой инструмента**, не кнопкой «скачать приложение».

## 4. Внешние сигналы (бесплатные ссылки и упоминания)

- [ ] Хабр: 1–2 статьи-исследования («Проанализировали 500 вакансий QA — вот что спрашивают») со ссылкой. Формат «данные + выводы» на Хабре живёт, прямую рекламу — режут.
- [ ] vc.ru: кейс запуска («Как я делаю AI-суфлёр для собеседований») — трафик + ссылка + комменты как исследование рынка.
- [ ] Ответы на профильные вопросы в TG-чатах/на Хабр Q&A со ссылкой на конкретный банк вопросов (не на главную).
- [ ] Каталоги стартапов RU (Product Radar, Startup Jedi и т.п.) — по 15 минут на сабмит.

## 5. YouTube как SEO (отдельная выдача)

Ролики «Вопросы на собеседовании QA — разбор с ответами» ранжируются в YouTube-поиске годами.
2 формата: (а) 5–10 мин разбор вопросов роли, (б) 30–60 сек Shorts «вакансия → мгновенный разбор»
(демо продукта). Дублировать Shorts в TikTok и VK Клипы без доп. затрат. Подробнее — 05-channels.md.
