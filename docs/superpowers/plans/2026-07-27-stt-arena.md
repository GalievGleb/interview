# STT Arena Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven development and execute each task in order.

**Goal:** Deliver a dedicated Electron STT comparison surface that runs the
same Russian technical-interview audio through Yandex, Deepgram, Soniox, and
OpenAI.

**Architecture:** Add a parallel multipart comparison endpoint to the existing
FastAPI backend and a standalone React route opened by Electron with
`--stt-arena`. Reuse the current provider adapters and secret store.

**Tech Stack:** FastAPI, pytest, React 19, TypeScript, Vitest, Electron 33.

## Global Constraints

- Do not include local Whisper.
- Do not copy API credentials into source or renderer storage.
- Normalize microphone recordings to mono PCM16 WAV at 16 kHz.
- Run selected cloud providers concurrently on identical audio bytes.
- Use Soniox Async File API for completed WAV recordings; its real-time
  WebSocket requires near-real-time pacing and is not a batch endpoint.
- Preserve existing SkillCue live behavior and API contracts.
