# SkillCue 0.1.0 Release Specification

## Goal

Publish the exact desktop dev state approved by the user on 2026-08-26 as the
stable SkillCue `0.1.0` release and make it available through the existing
GitHub updater and `skill-cue.ru` download aliases.

## Release contents

- Keep all current overlay, STT, answer-speed, screen-assist, HH automation,
  account switching, UI polish, macOS, and reliability changes in the worktree.
- Keep the test WAV fixture used by the voice-overlay end-to-end gate.
- Do not include credentials, generated build directories, caches, or local
  application data.
- Use stable semantic version `0.1.0` in every active package and Python API
  version source.
- Replace the obsolete unpublished `0.1.0` in-app note with one current entry;
  do not leave duplicate release-note versions.

## Required gates

- Release metadata validator and its tests pass for tag `v0.1.0`.
- Python backend test suite passes.
- Desktop tests, renderer typecheck, Electron typecheck, lint, and stable build
  pass from the release tree.
- The installed dev build passes overlay smoke plus the supplied WAV voice test,
  with voice-to-first-answer latency below four seconds.
- The stable packaged app starts and its bundled backend reports healthy.

## Publication

- Commit the complete intended dev work to `main` and push it to
  `GalievGleb/interview`.
- Create and push tag `v0.1.0`; the existing release workflow publishes Windows
  and both macOS architectures to `GalievGleb/SkillCue`.
- Wait for all release jobs and verify public `latest.yml`, installer, blockmap,
  macOS DMGs, and `skill-cue.ru` download redirects.
- No Raspberry Pi source deployment is required when `apps/api`, `landing`, and
  server configuration have no release diff; production still must be probed.
