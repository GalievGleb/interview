# Установка SkillCue на Mac без Apple Developer Program

Это тестовая сборка для Apple Silicon (arm64). Приложение подписано локально для
проверки целостности пакета, но не подписано Apple Developer ID и не прошло
нотариализацию Apple. macOS может потребовать ручное разрешение при первой
установке и после обновления. На Mac под управлением организации установка
может быть запрещена политикой администратора.

1. Скачайте DMG только по ссылке SkillCue, откройте его и перетащите
   `SkillCue.app` в «Программы». Если там уже есть SkillCue, завершите его и
   согласитесь на замену.
2. Откройте SkillCue из «Программ». Если macOS покажет «Apple не удалось
   подтвердить…», нажмите **«Готово»**. Дважды нажмите **«Настройки безопасности»**
   в окне DMG (либо откройте **Системные настройки → Конфиденциальность и
   безопасность** вручную). Прокрутите вниз и нажмите **«Всё равно открыть»**
   для SkillCue. Подтвердите паролем Mac или Touch ID, если потребуется, затем
   нажмите **«Открыть»**.
   После этого приложение можно запускать обычным двойным нажатием.
3. При использовании записи дайте разрешение на микрофон и на запись экрана и
   системного звука, затем перезапустите SkillCue, если macOS попросит.

Если macOS сообщает, что приложение **повреждено**, не отключайте Gatekeeper
для всего Mac. Сообщите нам имя скачанного файла и версию macOS, чтобы мы
проверили конкретный пакет. Сообщение о повреждении нельзя считать обычным
шагом установки.

Эта процедура описывает разрешённое Apple исключение для конкретного
приложения. Она не гарантирует установку на каждом Mac. Для обычного запуска
у всех покупателей без ручного исключения нужна подпись Developer ID и
нотариализация, доступные через платную Apple Developer Program.

В DMG вложена офлайн-инструкция **«Первый запуск.html»**. Ярлык настроек
открывает системную панель безопасности и сам не меняет разрешения.

Инструкция Apple:
https://support.apple.com/en-nz/102445
