# Alpha: проверка исправлений сессии 13 сентября

## Что меняется

- Ctrl+Shift+Enter: исправляющий запрос для SQL требует SQL, а не Python-функцию. Валидатор точности сохранён. По отчёту нельзя установить конкретный код отказа второго запроса: пикселей и кодов проверки в нём нет.
- В карточке снимка показано «Снимок экрана сделан», внутренние инструкции не выводятся как вопрос пользователя.
- Ctrl+\: вставляет последнюю завершённую фразу микрофона в поле задания, без отправки. Пока новая фраза распознаётся или проверяется на эхо, показывает ожидание вместо вставки предыдущей.
- Двухканальный транскрипт: краткий буфер микрофона позволяет убрать совпадение с системной дорожкой, даже когда микрофонный текст пришёл первым. Это текстовая защита от эха, не физическое разделение источников. Короткие реплики сохраняются.
- Alpha требует управляемую лицензию аккаунта; старый анонимный ключ не даёт доступ. Выход и восстановление гостевого состояния очищают управляемый ключ.
- Подтверждённому аккаунту без подписки выдаётся пробный доступ: 300 000 токенов, срок 14 дней с первого подтверждения почты. На сервере один общий счётчик по аккаунту между устройствами и обновлениями ключа. Лимит STT остаётся отдельным.
- Отчёт отдельно показывает ошибки экрана и live-событий.

## Порядок выпуска

1. Обновить account/gateway серверные файлы с резервной копией, без изменения лендинга, секретов или базы данных.
2. `GATEWAY_REQUIRE_ACCOUNT_TRIAL` оставить выключенным, пока Alpha проверяется. Без этого флага старый анонимный доступ ещё доступен старым клиентам; защита пока не завершена для публичного stable.
3. Собрать Alpha с публичными настройками Google OAuth и account API. Установить отдельно от Dev и stable.
4. Проверить вручную: гостю недоступны бесплатные AI-запросы; после Google входа доступ появляется; после выхода пропадает. Повторный вход не создаёт новый серверный лимит.
5. Показать SQL-задачу, нажать Ctrl+Shift+Enter дважды; проверить последующий вопрос и короткую подпись снимка.
6. Включить вопрос в Telegram; в транскрипте должна остаться системная реплика без микрофонного дубля. Сказать отличающуюся собственную фразу, дождаться распознавания и нажать Ctrl+\: она должна попасть в поле задания, не запуская ответ.
7. После принятия Alpha выпустить новый stable с account gate и только затем включить `GATEWAY_REQUIRE_ACCOUNT_TRIAL=1` на gateway. Это отклоняет новые и уже сохранённые анонимные trial-ключи, но не платные лицензии. Скрытие GitHub-релизов само по себе не отключает установленные копии.

## Ограничения

Привязка к Google не запрещает создание нескольких разных Google-аккаунтов. Защита от этого требует дополнительных серверных ограничений и мониторинга; не следует обещать полную защиту от злоупотреблений. Два одновременных голоса и повтор человеком слов интервьюера требуют отдельной живой проверки: текстовый фильтр не может всегда отличить сознательный повтор от акустического эха.

Из отчёта: ответ про изменяемость Python содержал ошибку — `set` изменяемый, неизменяемый вариант называется `frozenset`. Исправление транспорта не гарантирует фактическую точность всех ответов модели.
