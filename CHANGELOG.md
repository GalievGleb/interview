# Changelog

Все заметные изменения SkillCue. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии по [SemVer](https://semver.org/lang/ru/) (правила — `docs/VERSIONING.md`).

## [Unreleased]

## [0.0.21] — 2026-08-04

### Added
- **Несколько резюме HH:** можно отметить одно или несколько реальных резюме; для каждой вакансии SkillCue выбирает наиболее подходящее по пересечению ключевых слов. Старый одиночный выбор сохраняется для миграции существующих настроек.

### Changed
- Страница «Отклики» стала единым сценарием из трёх шагов: выбрать резюме, настроить выдачу, выбрать время. Ручные кнопки поиска и запуска убраны; осталась одна кнопка «Включить автоотклики».
- Включение автооткликов сохраняет настройки, активирует ежедневное расписание и сразу выполняет первый цикл поиска и откликов.

### Fixed
- После перезапуска приложения пустая локальная очередь больше не приводит к ложному сообщению «Новых вакансий нет»: перед откликами всегда выполняется новый поиск.

## [0.0.20] — 2026-08-04

### Added
- **Реальные резюме HH:** список резюме загружается из подтверждённой браузерной сессии и выбирается из готового списка вместо поиска по части названия.

### Changed
- Настройки поиска, расписание и очередь откликов показываются только после подтверждённого входа в HH.

### Fixed
- Вход по почте и одноразовому коду сразу возвращает на страницу резюме, не отправляет код повторно после автоматического подтверждения HH и восстанавливается после промежуточной страницы `/404`.

## [0.0.19] — 2026-08-04

### Added
- **Личный прогресс:** отдельная от карты готовности страница объединяет AI-разборы собеседований и независимо показывает технический уровень и HR/самопрезентацию.
- **AI-разбор из истории:** завершённая сессия разбирается автоматически, а сохранённую сессию можно повторно отправить на анализ одной кнопкой.
- **Вход в HH без пароля:** почта → одноразовый код с проверкой реально авторизованной сессии.

### Changed
- `Ctrl+Enter` зарегистрирован глобально на всё время работы SkillCue и срабатывает поверх Teams, Zoom, браузера и других приложений без предварительного клика по оверлею.
- Страница «Отклики» стала компактнее: поиск, ежедневный запуск и последние отклики собраны в ясный единый сценарий.
- Очередь HH выполняется без дневного ограничения и без искусственной паузы между вакансиями.
- Итоговый AI-анализ различает техническое, HR и смешанное интервью; HR-разговор больше не портит техническую карту знаний.

### Fixed
- Запоздавший финальный транскрипт теперь заменяет экранный fallback того же запроса и действительно запускает ответ, вместо зависания после `Ctrl+Enter`.
- Новый запрос отменяет только принадлежащий старому запросу анализ экрана, поэтому устаревший ответ не перезаписывает актуальный.
- Длинный ответ, панель управления и транскрипт прокручиваются как единый стек и больше не заполняют окно без возможности добраться до нижней части.
- Язык резюме и разбора задаётся явно, поэтому русская сессия не превращается в английский отчёт.
- Свежая непроверенная HH-сессия больше не показывается как подключённая, а неверный код не считается успешным входом.

## [0.0.18] — 2026-08-03

### Added
- **Автоотклики на HH:** полный цикл — поиск вакансий, открытие, выбор резюме, заполнение письма, подтверждение отправки (Playwright-автоматизация).
- **Авто-ответы в чат HH:** мониторинг непрочитанных сообщений рекрутеров и автоматические ответы через LLM (браузерная автоматизация).
- **OAuth-авторизация HH:** вход через HH API с сохранением токенов, без ручного ввода в браузере.
- **Вход в HH по телефону/почте:** автоматический вход через Playwright — достаточно указать телефон/почту и пароль.
- **Ежедневный авто-прогон:** планировщик откликов с настраиваемым временем и дневным лимитом.
- **Фильтры вакансий:** исключение по ключевым словам и компаниям, выбор региона, опыта, зарплаты.
- **UI страницы откликов:** новая страница «Очередь откликов» с OAuth, чатом и настройками фильтров.

### Changed
- `hhBrowserAssistant` расширен: `getPage()` для доступа из чат-браузера, улучшена обработка edge-кейсов.

## [0.0.17] — 2026-08-03

### Changed
- Ctrl+Enter выбирает активный аудиоканал, принимает короткие явные вопросы и дожидается запаздывающего финального транскрипта.
- При отсутствии реплики live-оверлей автоматически переходит к анализу экрана без тупикового сообщения об ошибке.
- Главный экран отдаёт больше места контексту вакансии и резюме; оверлей остаётся тёмным независимо от темы приложения.
- Установщик переведён в однокликовый режим: только прогресс, затем автоматический запуск SkillCue.

### Fixed
- Убраны зелёное выделение и увеличение поля ввода, из-за которых меню «…» открывалось только со второго клика.
- Нативные кнопки окна больше не остаются тёмно-синими в светлой теме, а верхний пункт сайдбара не обрезается.
- База с резюме, историей и знаниями перенесена в постоянные пользовательские данные; установщик мигрирует старую базу до замены приложения.

## [0.0.16] — 2026-08-02

### Added
- Явный AI-разбор завершённой сессии с сохранением сильных, слабых тем и карты знаний.
- Естественная озвучка вопросов мок-интервью через управляемый TTS с системным резервом.
- Фирменные панели установщика SkillCue.

### Changed
- Обновления скачиваются в одном потоке, ставятся автоматически вне live-сессии и перезапускают приложение без дополнительной кнопки.
- Настройки моделей скрыты: модель для каждого сценария теперь выбирается продуктовым планом автоматически.
- Главная страница, подготовка, формы и состояния загрузки стали компактнее.

### Fixed
- Повторные нажатия Ctrl+Enter теперь всегда выбирают самый свежий вопрос; устаревший STT или ответ не может перезаписать новый.
- Голосовые ответы мок-интервью распознаются по цельной исходной записи с контекстом вопроса и QA-терминов.
- Прозрачные области оверлея пропускают клики, меню и подсказки не обрезаются, Ctrl+Shift+H скрывает только оверлей.
- Русские сессии больше не получают английское резюме, история не перекрывает соседнюю панель, а загрузка резюме показывает прогресс и блокирует дубли.

## [0.0.9] — 2026-07-08

### Fixed
- Сборка релиза падала при бандле Whisper-модели: HF-кэш раскладывает файлы
  через симлинки (`snapshots/…` → `blobs/…`), которые electron-builder/7za не
  пакуют на Windows («The directory name is invalid»). `predownload_models.py`
  теперь разыменовывает симлинки (реальные копии) и удаляет `blobs`. Первая
  успешно публикуемая версия с офлайн-моделью, оплатой ЮKassa и deep-link
  активацией.

## [0.0.8] — 2026-07-08

### Fixed
- Deep-link активация (`skillcue://activate?key=…`) вела на страницу
  OSS-лицензий вместо активации. Теперь открывает **Настройки → Тарифы**,
  подставляет ключ в карточку лицензии и активирует его с понятным
  результатом (успех/ошибка) — работает в любом статусе, включая апгрейд
  basic→max у уже активной лицензии.

### Changed
- Страница успеха оплаты: честный текст (ключ показан здесь; на почту — чек, не
  ключ) + восстановление ключа возвратом на страницу в том же браузере (3 дня).

## [0.0.7] — 2026-07-08

### Added
- **Оплата через ЮKassa.** Кнопки платных тарифов на лендинге ведут на страницу
  оплаты (`/pay`), после оплаты гейтвей выпускает лицензионный ключ, страница
  успеха (`/pay-success`) его показывает. Подписка в приложении открывает ту же
  оплату. Сервер: `/gateway/checkout`, `/gateway/yookassa/webhook`,
  `/gateway/checkout/status` (billing.service.ts, yookassa.util.ts).
- **Авто-активация лицензии по ссылке `skillcue://activate?key=…`** — кнопка
  «Активировать в один клик» на странице успеха открывает установленное
  приложение и активирует ключ без ручного копирования.
- Кнопка «Скачать SkillCue» на странице успеха — для купивших до установки.

### Changed
- Установщик: Whisper **tiny** бандлится в релиз (CI-шаг предзагрузки) →
  первый запуск офлайн и без докачки ~460 МБ с HuggingFace. Забандленная
  модель автоматически становится дефолтом STT при первом запуске.

## [0.1.6] — 2026-07-07

### Added
- `scripts/release.ps1` (+ `release.bat` для двойного клика) — выпуск новой
  версии одной командой: bump + commit + tag + push, CI сам публикует установщик.

### Notes
- Приложение работает через управляемый гейтвей (ключ провайдера — на сервере,
  не в установщике). ⚠️ На проде OpenRouter начал отдавать 403 (Cloudflare
  гео-блок IP сервера) — для работы ИИ нужен не-РФ egress-прокси на гейтвее.

## [0.1.5] — 2026-07-07

### Changed
- Первый рабочий авто-релиз в `ScillCue`: стабильное имя установщика
  `SkillCue-Setup.exe`, публикация сразу (`releaseType: release`), настроен
  secret `SCILLCUE_RELEASE_TOKEN`.

## [0.1.4] — 2026-07-07

### Fixed
- Релизная сборка: `electron-builder` не мог определить версию Electron в

## [0.1.3] — 2026-07-07 (не опубликован — сборка падала)

### Added
- Выбор тем перед mock-интервью: снимите темы, где уже уверены — вопросы
  сгенерируются только по выбранным.

### Changed
- Работа ИИ полностью через управляемый гейтвей: пользователь не вводит ключ
  OpenRouter, каталог моделей подтягивается автоматически, токены/расходы нигде
  не показываются (убраны карточка расходов и цифры бюджета, тарифы без «N млн
  токенов», сайдбар без статуса ключа).
- Тёмный титлбар без белой системной рамки; убраны лишние индикаторы
  (traffic-lights, «Ожидание», статус AI-ключа) и крупный виджет Whisper.

### Fixed
- Контраст текста в подготовке (светлая тема), позиция переключателей,
  спокойный UX при холодном старте бэкенда (без ложных «нет ключа / Failed to
  fetch»).

## [0.1.2] — 2026-07-06

### Added
- Managed SkillCue Cloud trial: fresh installs can use the gateway without asking
  the user for an OpenRouter API key.
- Gateway endpoint `/gateway/trial` issues a limited signed trial license and
  keeps the normal Redis token quota path.
- Серверный гейтвей лицензий (`apps/api`): OpenAI-совместимый прокси `/v1/*`,
  офлайн-проверка Ed25519-ключей, учёт токенов по тарифам в Redis, выпуск ключей
  `/gateway/issue`, публичный `/health` для мониторинга.
- Облачные STT-движки: Deepgram Nova-3 (стриминг) и Яндекс SpeechKit v3 (gRPC) —
  выбираются в настройках, сравниваются в STT-бенчмарке.
- Деплой на VPS: `deploy.py` + `setup-vps.sh` (гейтвей+Redis+лидбот, swap, не
  трогает чужой :80), `setup-web.sh` (домен + TLS), `status.sh`, `README.md`.
- Лидбот SkillCue переехал на сервер (24/7, systemd, самовосстановление).
- План версий (`docs/VERSIONING.md`) и этот changelog.

### Changed
- Desktop release scripts now build the frozen Python backend by default before
  packaging the installer.
- Startup UX no longer exposes backend warmup as a user-facing warning.
- Релизы десктопа публикуются в публичный репозиторий `GalievGleb/ScillCue`
  (код остаётся в приватном `interview`); ссылки «Скачать» и автообновление
  выровнены на него.
- Лендинг: canonical/OG на `skill-cue.ru`, готовый к заполнению сниппет Метрики.

### Fixed
- Freshly downloaded installer no longer ships without `skillcue-backend.exe`
  when built through the normal `dist`/`dist:desktop` command.
- Removed the native Electron menu bar from packaged desktop windows.
- Sidebar and live preflight no longer show dev-oriented backend/API-key noise
  during normal startup.

### Security
- Redis AOF включён — учёт токенов переживает сбой (потеря ≤1 сек).
- fail2ban для sshd на сервере (блок брутфорса).
