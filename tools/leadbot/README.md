# SkillCue Lead Bot

Telegram-бот приёма лидов: человек присылает вакансию → бот сохраняет лид в `leads.jsonl`
и уведомляет тебя → ты отвечаешь разбором. Зависимостей нет — только Python (>= 3.11).

## Запуск

```powershell
py -3.12 tools/leadbot/leadbot.py        # запуск бота (или start-leadbot.bat — с автоперезапуском)
py -3.12 tools/leadbot/leadbot.py --setup  # оформить профиль: имя, описания, меню команд
```

Первый запуск создаёт `config.json` — впиши токен от [@BotFather](https://t.me/BotFather)
(/newbot). Свой `chat_id` бот покажет после твоего `/start`, впиши его как `admin_chat_id`.

`--setup` применяет тексты из констант в начале `leadbot.py` (BOT_NAME, BOT_DESCRIPTION…) —
правишь текст → перезапускаешь `--setup`. Аватар API не умеет: только BotFather `/setuserpic`.

## Что умеет бот (логика)

- `/start` — захватывающее приветствие + кнопка «⬇️ Скачать SkillCue» (и «📣 Канал», если
  в конфиге задан `channel_url`); `/start utm_метка` пишет источник в лид.
- Длинный текст (≥ 300 символов) — считается **вакансией**: лид `kind=vacancy`, тебе
  уведомление «🔥 ВАКАНСИЯ НА РАЗБОР».
- Короткий текст — **вопрос**: лид `kind=message`, уведомление «✉️ Сообщение».
- Фото/файл/голос — пересылается тебе как есть, лиду — просьба прислать текстом.
- `/help` — инструкция «как получить бесплатный разбор».

## Команды администратора (в чате с ботом)

- **Ответить лиду: просто сделай reply на уведомление о лиде** — бот перешлёт твой текст.
- `/reply <chat_id> <текст>` — то же вручную.
- `/key <basic|max> <дней|0> <email> [chat_id]` — выпустить лицензионный ключ
  (0 = бессрочный; с chat_id ключ сразу уходит покупателю в личку).
- `/stats` — сколько лидов всего/сегодня, по типам.

## Продажа тарифов (полный цикл)

1. Кнопка «Оплатить» в приложении (PlanPicker) открывает бота с deep-link
   `?start=buy_<план>_<период>`; команда `/buy` делает то же вручную.
2. Бот показывает покупателю цену и инструкцию оплаты (`pay_url` из config.json;
   пока пусто — просит написать в чат, реквизиты шлёшь реплаем).
3. Тебе прилетает «🤑 ХОЧЕТ КУПИТЬ» с готовой командой выдачи ключа.
4. После оплаты: `/key max 30 email@покупателя <chat_id>` — бот минтит
   Ed25519-ключ (тот же формат, что проверяет apps/api-py) и отправляет
   покупателю с инструкцией активации.

Требования: пакет `cryptography` (`py -3.12 -m pip install cryptography`) и приватный
ключ `apps/api-py/.license_signing_key` (путь переопределяется в config.json →
`signing_key_path`). **При переезде бота на сервер скопируй этот файл** (chmod 600)
и поставь cryptography.

Разбор вакансии делай своим же продуктом (вставь вакансию в SkillCue → скопируй вопросы
и риски → ответь реплаем). Это concierge-режим: медленно, зато первые лиды получают
вау-качество.

## Файлы (в git не попадают, см. .gitignore)

- `config.json` — токен и настройки (секрет!)
- `leads.jsonl` — все лиды с временными метками (kind: start / vacancy / message / non_text / admin_reply)
- `state.json` — служебный (offset Telegram)

## Когда перерастёшь ручной режим

Следующий шаг — автоматический разбор: бот сам зовёт `apps/api-py` (эндпоинт vacancy)
и отвечает мгновенно. Скажи Claude «подключи leadbot к api-py» — точка входа одна:
`handle_user`, ветка `kind=vacancy`.
