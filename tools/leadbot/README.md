# SkillCue Lead Bot

Telegram-бот приёма лидов: человек присылает вакансию → бот сохраняет лид в `leads.jsonl`
и пересылает тебе → ты отвечаешь разбором через `/reply`. Зависимостей нет — только Python.

## Запуск за 5 минут

1. **Создай бота:** в Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` →
   имя `SkillCue` → username, например `skillcue_support_bot` (должен кончаться на `bot`).
   Скопируй токен вида `1234567:AA...`.
2. **Первый запуск** (создаст конфиг):
   ```powershell
   py -3.12 tools/leadbot/leadbot.py
   ```
3. Впиши токен в `tools/leadbot/config.json` → запусти снова.
4. **Привяжи себя как админа:** напиши своему боту `/start` — он покажет твой `chat_id`.
   Впиши его в `config.json` как `admin_chat_id` → перезапусти.
5. Проверка: попроси кого-нибудь (или второй аккаунт) прислать боту текст —
   тебе придёт уведомление `🔥 Новый лид` с `chat_id`.

## Как отвечать лидам

В чате со своим ботом:
- `/reply <chat_id> текст разбора` — отправить ответ лиду
- `/leads` — сколько всего лидов накоплено

Разбор вакансии делай своим же продуктом (вставь вакансию в SkillCue → скопируй вопросы
и риски → `/reply`). Это concierge-режим: медленно, зато первые лиды получают вау-качество.

## Атрибуция источников

Ссылка вида `https://t.me/<бот>?start=tg_seeding_kanal1` — метка попадёт в `leads.jsonl`
(поле `utm`). Используй разные метки для каждого канала посева — увидишь, откуда лиды.

## Файлы (в git не попадают, см. .gitignore)

- `config.json` — токен и настройки (секрет!)
- `leads.jsonl` — все лиды с временными метками
- `state.json` — служебный (offset Telegram)

## Когда перерастёшь ручной режим

Следующий шаг — автоматический разбор: бот сам зовёт `apps/api-py` (эндпоинт vacancy)
и отвечает мгновенно. Скажи Claude «подключи leadbot к api-py» — код уже подготовлен к этому
(обработчик лида в одном месте, `handle_message`).
