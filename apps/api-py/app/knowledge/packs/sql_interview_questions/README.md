# SQL Knowledge Pack (curated)

Курируемый пак ответов по SQL / базам данных для QA Automation интервью.
В отличие от питон-пака здесь нет community-слоя — только проверенные записи
в `curated.json`, написанные в формате «сказать вслух» (короткие, разговорные,
с QA-ракурсом, термины на английском).

- Роутинг: `app/services/knowledge_pack.py` → `is_sql_question` / `detect_pack`.
  Питон-сигналы выигрывают при пересечении; QA-темы (pytest, POM, CI/CD…) в пак
  не попадают — их ведут domain hints.
- Инъекция: до 2 лучших записей по пересечению ключевых слов, заголовок
  «SQL KNOWLEDGE PACK (verified reference…)».
- Добавление записи: entry = `{id, keywords[], question, answer}`.
  `keywords` — слова, которые реально встречаются в формулировках вопроса
  (включая склонения: «джойн», «джойны»), матчинг — точное совпадение слова.
