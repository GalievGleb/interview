# SkillQ premium design prototype

This folder contains a static design prototype for **SkillQ**, a private AI copilot for technical interviews.

Open:

- `SkillQ.prototype.html`

The prototype includes:

- 3 visual directions:
  - Warm Minimal Assistant
  - Technical Command Workspace
  - Stealth Interview Copilot
- Recommended direction and rationale
- Refined full prototype for:
  - marketing website
  - desktop app live interview screen
  - resume / legend setup
  - history
  - settings
  - overlay normal mode
  - overlay minimal/hidden modes
  - shared design system

This is a design handoff artifact, not production code to copy 1:1. Use it to align product direction, layout hierarchy, tone, and component styling before implementing the redesign in the desktop app and landing page.
