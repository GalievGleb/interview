SQL: страна города Salzburg

Выведите название страны, в которой находится город Salzburg. Назовите столбец результата country_name. Напишите один SELECT-запрос.

Схема базы данных
Countries(id INTEGER PRIMARY KEY, name TEXT)
Regions(id INTEGER PRIMARY KEY, name TEXT, countryid INTEGER → Countries.id)
Cities(id INTEGER PRIMARY KEY, name TEXT, regionid INTEGER → Regions.id)

Город связан с регионом через Cities.regionid, регион — со страной через Regions.countryid.
